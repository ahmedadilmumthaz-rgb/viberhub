# Viber Hub Desktop Companion (Electron)

## Purpose & Operating Boundaries
The Desktop Companion is designed to assist human operators on macOS and Windows:
- Authenticates securely with your self-hosted Viber Hub instance.
- Notifies the operator when a campaign package is approved and ready for dispatch.
- Provides 1-click clipboard population and launches the local Viber Desktop client via standard operating system protocols (`viber://` or application launch).
- Leaves the final review and sending decision strictly to the human operator.
- Adheres to Viber's Fair Usage Policy: **zero unattended bots, reverse-engineered APIs, or automated clicks**.
